# Security

This package starts a Vault or OpenBao **dev server** for tests. A dev server is unsealed, keeps data in memory and uses a known root token. Never expose such a container to a network you do not control and never put real secrets in it.

## Reporting a vulnerability

Please do not open a public issue. Use [private vulnerability reporting](https://github.com/ferhatblnk/drydock-testcontainers-vault/security/advisories/new) on GitHub. You can expect a first answer within a week.
